# DES voice architecture

DES is the highest-value remaining read-only gap because it is the hub for company overview, snapshot valuation, ownership, capital structure, dividend, beta and short-interest facts.

Every request binds one exact security. Explicit handoffs may open G, N, CHAT, FA, EM or ANR for that same identity. Grounded narration reads only fields observed in the matching Godel DES panel. Valuation ratios require `x` units; ownership and dividend yield require percent units. Missing values, security mismatches and corrupt units fail closed. Runtime handoffs remain disabled pending exact live callback proof.
