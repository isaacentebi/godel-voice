# PAT, PRT, and KELLY voice architecture

These live-undocumented tools remain disabled until their exact native grammar and controls are captured.

`PAT` binds one exact security and one live pattern identity. Occurrence count and forecast horizon are accepted only when they match a current live option. Narration is limited to observed occurrence count, horizon, mean and median forward returns, and positive-rate statistics.

`PRT` accepts a bounded, unique batch of exact live pattern identities, an exact live ranking option, and an explicit show/hide realized-outcomes state. Ranked narration requires contiguous observed ranks and finite realized outcomes. No ranking or result is inferred.

`KELLY` accepts a finite positive starting balance with an explicit or authoritative currency, win probability spoken as percent and normalized to `0..1`, and bet percent bounded to `0..100`. Context may fill omitted values only from authenticated current simulator state. Simulation outputs must be finite observed Godel values.

All three surfaces are educational statistical tools, not advice. Buy, sell, order, trade, wager, or execution language is blocked. Corrections replace earlier clauses; contradictions or unresolved dynamic values make the whole configuration non-executable.
