# IPO, WJI, and remaining HDS voice architecture

## IPO

Previous/Next paging binds the exact current page identity to one exact destination identity supplied by the live panel. Prospectus, S-1, and announcement navigation requires explicit open/follow/visit language, one exact selected IPO row, a matching document type, and its exact HTTPS destination.

IPO's documented XLSX export remains disabled. The attempted live proof did not establish a trustworthy completed artifact, so documentation alone cannot promote it.

## WJI

WJI narration is allowed only from exact current `Godel WJI panel` facts: Green percentage, sentiment label, Bull/Bear/Pink/Green counts, source channel, message count, and observation time. Green percentage is cross-checked against Green/Pink counts. WJI is chat-emote sentiment, not a price forecast, trading signal, or recommendation. Export-looking controls remain unsupported because their semantics are unresolved.

## HDS remainder

The existing verified Table, Treemap, and Bubble controls remain live and unchanged. New row navigation binds an exact selected holder ID to the exact previous/next holder ID. Original 13F navigation requires explicit intent, one exact selected holder, and an exact SEC Archives URL. These new actions remain runtime-disabled pending live postcondition proof.

HDS export remains disabled because its format is unresolved. Corrections supersede prior directions; direct direction conflicts or any unsupported/export clause block the complete compound step.
