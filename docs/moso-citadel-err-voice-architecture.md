# MOSO, CITADEL, and ERR architecture

These commands are live-undocumented and expose no verified nested control grammar, so all three remain open-only with zero executable nested actions.

MOSO means ranked active option contracts. It stays distinct from MOST stock activity and OMON security-specific option chains. Narration requires exact observed contiguous rows and never infers filters, sorting, navigation, export or orders.

CITADEL is treated only as the title of Godel's observed overview. Grounded narration requires exact panel text. The assistant never implies affiliation with a Citadel entity, endorsement, holdings, strategy, performance or investment advice.

ERR may open Godel's manual support surface. Submit/file/report language is consequential and returns only a confirmation-required manual handoff—never a populated or unattended mutation. Voice never retains the report body or attaches logs, diagnostics, screenshots, cookies, session identifiers, credentials, tokens, payment data or other secrets.
